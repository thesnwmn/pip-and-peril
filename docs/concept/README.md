# Concept & direction

The canonical design brief is [`../concept.md`](../concept.md).

This folder is for **expanded concept material** as the game's direction deepens — art direction,
tone references, pillar deep-dives, run-flow studies. The **Thinker** owns and grows it.

## Expanded concept docs

- [`tiles-and-props.md`](tiles-and-props.md) — tile variety direction: the four layers of a tile
  (exit layout × interior archetype × room type × props), the snapping invariant, an archetype
  catalogue, and the props system. Visual exploration in **POC 6** (`public/poc/tiles/`); seeds in
  `IDEAS.md` (008–011).
- [`in-run-items.md`](in-run-items.md) — in-run item system direction: the two-layer (meta vs.
  in-run) philosophy, the persistence spectrum, usage registers, item categories (healing, stat
  boosts, armour, utility, weapon coatings), the encounter interaction model (resolve window), and
  the Luck / Tenacity item class distinction, and five additional categories identified from
  genre survey (knowledge, charged items, death prevention, cursed items, dice-face manipulation)
  with passive trinkets noted as deferred. Seeds in `IDEAS.md` (019–022, 024–028).
