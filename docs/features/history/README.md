# Archived feature specs

When a feature ships, the Engineer moves its spec from `docs/features/` into this folder and
appends a `## Shipped` section with the implementation evidence (what was built, test results,
play-test instructions, and PR link).

[`BACKLOG_HISTORY.md`](../../../BACKLOG_HISTORY.md) holds a short summary entry for each item
linking back here.
